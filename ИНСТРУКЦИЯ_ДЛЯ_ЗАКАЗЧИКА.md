# Инструкция для заказчика

## 📦 Что в архиве

Проект навыка Яндекс.Алисы "Музей техники и предметов быта XX века" содержит:

### Основные файлы:
- `main.py` - обработчик Cloud Function
- `utils.py` - вспомогательные функции
- `config.py` - конфигурация
- `requirements.txt` - зависимости Python

### Вспомогательные файлы:
- `convert_excel_to_json.py` - скрипт для конвертации Excel в JSON
- `test_local.py` - скрипт для локального тестирования

### Конфигурация:
- `intents.json` - интенты для навыка (нужно импортировать в dialogs.yandex.ru)
- `items.json` - база данных экспонатов (395 экспонатов)

### Документация:
- `README.md` - полная инструкция по развертыванию
- `ПРОВЕРКА.md` - инструкция по проверке работы программы
- `ИНСТРУКЦИЯ_ДЛЯ_ЗАКАЗЧИКА.md` - этот файл

## 🚀 Быстрый старт

1. **Распакуйте архив** в удобную папку

2. **Прочитайте README.md** - там подробная инструкция по развертыванию

3. **Основные шаги:**
   - Создайте Object Storage в Yandex Cloud
   - Загрузите `items.json` в Object Storage
   - Создайте Cloud Function и загрузите файлы проекта
   - Настройте переменные окружения
   - Подключите функцию к навыку в dialogs.yandex.ru
   - Импортируйте интенты из `intents.json`

## 📋 Что нужно сделать перед развертыванием

1. **Проверьте items.json:**
   - Убедитесь, что все экспонаты на месте (395 экспонатов)
   - При необходимости обновите через `convert_excel_to_json.py`

2. **Настройте переменные окружения в Cloud Function:**
   ```
   BUCKET=ваш_бакет
   FILE=items.json
   S3_ENDPOINT=https://storage.yandexcloud.net
   AWS_ACCESS_KEY_ID=ваш_ключ
   AWS_SECRET_ACCESS_KEY=ваш_секрет
   AWS_REGION=ru-central1
   WORK_MODE=cloud
   ```

3. **Импортируйте интенты:**
   - Откройте dialogs.yandex.ru
   - Перейдите в раздел "Интенты"
   - Импортируйте `intents.json` или создайте интенты вручную

## 📞 Поддержка

2. Проверьте логи в Cloud Functions
3. Используйте `test_local.py` для локального тестирования

## 📝 Важные замечания

1. **Обновление базы данных:**
   - Обновите `items.json` в Object Storage
   - Создайте новую версию Cloud Function
   - Подробнее в README.md, раздел "Обновление базы данных"

2. **Логи:**
   - Все запросы логируются в Cloud Functions
   - Формат: `[time] number=N status=ok|no_description|invalid_phrase part=K`

3. **Тестирование:**
   - Используйте `test_local.py` для проверки перед развертыванием
   - После развертывания тестируйте через навык Алисы
