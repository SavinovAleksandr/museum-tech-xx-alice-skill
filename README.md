# Навык Яндекс.Алисы "Музей техники XX века"

Полностью рабочий навык для Яндекс.Алисы, который рассказывает об экспонатах музея техники и предметов быта XX века.

## 📋 Описание

Навык позволяет пользователям узнавать об экспонатах музея по их номерам. Поддерживаются следующие команды:
- Поиск по номеру экспоната
- Команда "дальше" для продолжения описания
- Команда "повтори" для повторения текущей части
- Команда "сначала" для перезапуска описания с начала

## ⚡ Быстрый старт

1. **Конвертация Excel → JSON:**
   ```bash
   python convert_excel_to_json.py "/mnt/data/Описание экспонатов, 2 столбца.xlsx" items.json
   ```

2. **Локальное тестирование:**
   ```bash
   export WORK_MODE=local
   python test_local.py
   ```

3. **Развертывание в Yandex Cloud:**
   - Создайте Object Storage и загрузите `items.json`
   - Создайте Cloud Function и загрузите файлы проекта
   - Настройте переменные окружения (см. раздел "Настройка переменных окружения")
   - Подключите функцию к навыку в dialogs.yandex.ru

## 🚀 Развертывание проекта

### 1. Подготовка данных

#### 1.1. Конвертация Excel в JSON

Если у вас есть Excel файл с описаниями экспонатов (2 столбца: номер и описание):

```bash
python convert_excel_to_json.py <путь_к_excel_файлу> [путь_к_output]
```

Пример:
```bash
python convert_excel_to_json.py "/mnt/data/Описание экспонатов, 2 столбца.xlsx" items.json
```

Скрипт автоматически:
- Очищает текст от лишних переносов строк
- Преобразует номера в строки
- Удаляет пустые строки
- Сохраняет в формате UTF-8

#### 1.2. Формат items.json

Файл должен иметь следующую структуру:

```json
{
  "1": "Описание первого экспоната...",
  "2": "Описание второго экспоната...",
  ...
}
```

### 2. Создание Object Storage

1. Перейдите в [Yandex Cloud Console](https://console.cloud.yandex.ru/)
2. Выберите каталог или создайте новый
3. Перейдите в раздел **Object Storage**
4. Нажмите **Создать бакет**
5. Укажите имя бакета (например, `museum-tech-xx`)
6. Выберите тип доступа: **Публичный** или **Приватный** (рекомендуется Приватный)
7. Создайте бакет

### 3. Загрузка items.json в Object Storage

1. В созданном бакете нажмите **Загрузить**
2. Выберите файл `items.json`
3. Дождитесь завершения загрузки
4. Убедитесь, что файл отображается в списке объектов

### 4. Создание сервисного аккаунта и роли

1. Перейдите в раздел **Service accounts** (Сервисные аккаунты)
2. Нажмите **Создать сервисный аккаунт**
3. Укажите имя (например, `museum-function-sa`)
4. Нажмите **Добавить роль** и выберите:
   - `storage.viewer` (для чтения объектов)
   - `storage.uploader` (если нужна загрузка файлов)
5. Нажмите **Создать**

### 5. Создание статического ключа доступа

1. Откройте созданный сервисный аккаунт
2. Перейдите на вкладку **Ключи доступа**
3. Нажмите **Создать новый ключ** → **Статический ключ доступа**
4. Сохраните `Access Key ID` и `Secret Access Key` (они понадобятся для переменных окружения)

### 6. Создание Cloud Function

#### 6.1. Через Yandex Cloud Console

1. Перейдите в раздел **Cloud Functions**
2. Нажмите **Создать функцию**
3. Укажите:
   - Имя функции: `museum-tech-xx-handler`
   - Описание: `Обработчик навыка Музей техники XX века`
4. Нажмите **Создать**

#### 6.2. Настройка функции

1. Откройте созданную функцию
2. Перейдите на вкладку **Редактор**
3. Загрузите все файлы проекта:
   - `main.py`
   - `utils.py`
   - `config.py`
   - `requirements.txt`

#### 6.3. Настройка точки входа

1. Перейдите на вкладку **Общие сведения**
2. В разделе **Точка входа** укажите: `main.handler`
3. В разделе **Время выполнения** выберите: `python310`
4. В разделе **Таймаут, сек** укажите: `10`
5. В разделе **Память** укажите: `128 МБ`

### 7. Настройка переменных окружения

1. Перейдите на вкладку **Редактор** функции
2. Откройте раздел **Переменные окружения**
3. Добавьте следующие переменные:

```
BUCKET=museum-tech-xx
FILE=items.json
S3_ENDPOINT=https://storage.yandexcloud.net
AWS_ACCESS_KEY_ID=<ваш_access_key_id>
AWS_SECRET_ACCESS_KEY=<ваш_secret_access_key>
AWS_REGION=ru-central1
WORK_MODE=cloud
```

**Важно:** Замените значения на реальные из вашего аккаунта.

### 8. Деплой функции

#### 8.1. Через консоль

1. Убедитесь, что все файлы загружены
2. Нажмите **Создать версию**
3. Дождитесь завершения деплоя (статус: **Активна**)

#### 8.2. Через CLI (опционально)

Установите Yandex Cloud CLI и выполните:

```bash
yc serverless function version create \
  --function-name museum-tech-xx-handler \
  --runtime python310 \
  --entrypoint main.handler \
  --memory 128m \
  --execution-timeout 10s \
  --source-path . \
  --environment BUCKET=museum-tech-xx,FILE=items.json,...
```

### 9. Настройка навыка в dialogs.yandex.ru

1. Перейдите на [dialogs.yandex.ru](https://dialogs.yandex.ru/)
2. Создайте новый навык или откройте существующий
3. Перейдите в раздел **Backend** (Бэкенд)
4. Выберите **Yandex Cloud Functions**
5. Укажите:
   - Функция: `museum-tech-xx-handler`
   - Версия: `$latest` или конкретная версия
6. Сохраните настройки

### 10. Настройка интентов

1. Перейдите в раздел **Интенты** в настройках навыка
2. Импортируйте файл `intents.json` или создайте интенты вручную:

#### Интенты:

- **get_number** - получение номера экспоната (слот `YANDEX.NUMBER`)
- **next** - команда "дальше"
- **repeat** - команда "повтори"
- **restart** - команда "сначала"

3. Для интента `get_number` добавьте слот:
   - Имя слота: `number`
   - Тип: `YANDEX.NUMBER`

## 🔄 Обновление базы данных

### Инструкция для заказчика: как работать с базой экспонатов

#### Как добавить новые экспонаты

**Способ 1: Добавление вручную в JSON файл**

1. Откройте файл `items.json` в любом текстовом редакторе
2. Добавьте новую строку в формате:
   ```json
   "396": "Описание нового экспоната номер 396...",
   ```
3. Сохраните файл
4. Загрузите обновленный файл в Object Storage (см. ниже)

**Способ 2: Через Excel (рекомендуется для массового добавления)**

1. Откройте ваш Excel файл с экспонатами
2. Добавьте новые строки:
   - Первый столбец: номер экспоната (например, 396, 397, 398...)
   - Второй столбец: описание экспоната
3. Сохраните Excel файл
4. Запустите скрипт конвертации:
   ```bash
   python convert_excel_to_json.py "путь/к/вашему/файлу.xlsx" items.json
   ```
5. Загрузите обновленный `items.json` в Object Storage

#### Как обновить/заменить файл с экспонатами

1. **Подготовьте новый файл `items.json`:**
   - Отредактируйте существующий файл, или
   - Создайте новый через конвертацию Excel

2. **Загрузите в Object Storage:**
   - Откройте [Yandex Cloud Console](https://console.cloud.yandex.ru/)
   - Перейдите в раздел **Object Storage**
   - Откройте ваш бакет (тот, который указан в переменной окружения `BUCKET`)
   - Найдите файл `items.json` в списке объектов
   - Нажмите на три точки рядом с файлом → **Удалить**
   - Нажмите кнопку **Загрузить** → выберите новый файл `items.json`
   - Дождитесь завершения загрузки

3. **Обновите версию Cloud Function:**
   - Откройте [Cloud Functions](https://console.cloud.yandex.ru/functions)
   - Найдите вашу функцию (например, `museum-tech-xx-handler`)
   - Нажмите на функцию, чтобы открыть её
   - Перейдите на вкладку **Редактор**
   - Нажмите кнопку **Создать версию** (в правом верхнем углу)
   - Дождитесь завершения создания версии (статус должен стать "Активна")
   - Готово! Новая версия будет использовать обновленный файл

**Важно:** После обновления файла в Object Storage функция автоматически загрузит новые данные при следующем "холодном старте" (когда функция не использовалась некоторое время). Если нужно обновить данные немедленно, создайте новую версию функции.

#### Как перезалить функцию/обновить версию

**Если вы изменили код функции:**

1. Откройте функцию в Cloud Functions
2. Перейдите на вкладку **Редактор**
3. Внесите изменения в файлы (`main.py`, `utils.py`, `config.py` и т.д.)
4. Нажмите **Создать версию**
5. Дождитесь завершения (статус: "Активна")

**Если вы только обновили `items.json` в Object Storage:**

- Новая версия функции не обязательна, но рекомендуется для гарантии
- Или просто подождите несколько минут — функция загрузит новые данные при следующем запросе

#### Где смотреть логи

1. Откройте [Cloud Functions](https://console.cloud.yandex.ru/functions)
2. Найдите и откройте вашу функцию
3. Перейдите на вкладку **Логи**
4. Вы увидите все запросы в формате:
   ```
   [2025-11-22 13:15:30] number=5 status=ok part=0
   [2025-11-22 13:15:45] number=5 status=ok part=1
   [2025-11-22 13:16:00] number=999 status=no_description
   [2025-11-22 13:16:15] number=None status=invalid_phrase
   ```

**Что означают логи:**
- `number=5` — запрошен номер экспоната 5
- `status=ok` — описание найдено и выдано
- `status=no_description` — такого номера нет в базе
- `status=invalid_phrase` — непонятная команда
- `part=0` — выдана первая часть описания (0, 1, 2...)

**Совет:** Используйте логи для анализа:
- Какие номера чаще всего спрашивают
- Какие номера отсутствуют в базе (status=no_description)
- Какие команды не распознаются (status=invalid_phrase)

## 📝 Логирование

Функция логирует все запросы в формате:

```
[YYYY-MM-DD HH:MM:SS] number=N status=ok|no_description|invalid_phrase part=K
```

Где:
- `number` - номер запрошенного экспоната
- `status` - статус обработки:
  - `ok` - успешная обработка
  - `no_description` - экспонат не найден
  - `invalid_phrase` - непонятная команда
- `part` - номер части описания (если применимо)

Логи можно посмотреть в разделе **Логи** функции в Cloud Functions.

## 🐛 Локальное тестирование

Для локального тестирования без Object Storage:

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Установите переменную окружения:
```bash
export WORK_MODE=local
```

3. Убедитесь, что файл `items.json` находится в корне проекта

4. Запустите тестовый скрипт:

```python
# test_local.py
import json
from main import handler

# Тестовый запрос
event = {
    "session": {
        "new": True,
        "session_id": "test",
        "user_id": "test"
    },
    "request": {
        "command": "номер 1",
        "original_utterance": "номер 1",
        "nlu": {
            "intents": {
                "get_number": {
                    "slots": {
                        "number": {
                            "value": 1
                        }
                    }
                }
            }
        }
    },
    "version": "1.0"

result = handler(event, None)
print(json.dumps(result, ensure_ascii=False, indent=2))
```
