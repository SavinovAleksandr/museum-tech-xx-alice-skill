# Как проверить, что программа работает

## Быстрая проверка (локально)

### Шаг 1: Установите зависимости

```bash
cd "/Users/anna/Documents/Фриланс/Музей в Алисе"
source venv/bin/activate
pip install boto3 --quiet
```

Если виртуального окружения нет, создайте его:
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Шаг 2: Запустите тесты

```bash
python test_local.py
```

Вы увидите результаты всех тестов:
- ✅ Приветствие при запуске
- ✅ Запрос номера экспоната
- ✅ Команда "дальше"
- ✅ Команда "повтори"
- ✅ Команда "сначала"
- ✅ Запрос несуществующего номера
- ✅ Непонятная команда

### Шаг 3: Проверьте результаты

**Успешный результат:**
- Все тесты должны завершиться с "✓ Тест выполнен успешно"
- В ответах должна быть правильная структура JSON
- Логирование должно показывать: `[time] number=N status=ok|no_description|invalid_phrase part=K`

## Что проверяют тесты

1. **Приветствие:** Приветствует пользователя при запуске навыка
2. **Поиск экспоната:** Находит экспонат по номеру (например, номер 1)
3. **Команда "дальше":** Переходит на следующую часть описания
4. **Команда "повтори":** Повторяет текущую часть описания
5. **Команда "сначала":** Начинает описание с начала
6. **Несуществующий номер:** Корректно обрабатывает отсутствие экспоната (номер 999)
7. **Непонятная команда:** Корректно обрабатывает непонятные фразы

## Ручная проверка отдельных функций

### Проверка загрузки данных

```bash
python3 -c "import json; data = json.load(open('items.json', 'r', encoding='utf-8')); print(f'Экспонатов: {len(data)}'); print(f'Номера: от {min(map(int, data.keys()))} до {max(map(int, data.keys()))}')"
```

**Ожидаемый результат:** Экспонатов: 395, Номера: от 1 до 395

### Проверка разбиения текста на части

```bash
python3 -c "
import sys
sys.path.insert(0, '.')
os.environ['WORK_MODE'] = 'local'
import os
from utils import split_description_by_sentences
text = 'Предложение 1. Предложение 2. Предложение 3.' * 200
parts = split_description_by_sentences(text, 1024)
print(f'Текст разбит на {len(parts)} частей')
for i, part in enumerate(parts):
    print(f'Часть {i}: {len(part)} символов')
"
```

**Ожидаемый результат:** Текст должен быть разбит на части, каждая ≤ 1024 символов

## Проверка после развертывания в Yandex Cloud

### 1. Проверка через консоль Cloud Functions

1. Откройте [Cloud Functions](https://console.cloud.yandex.ru/functions)
2. Найдите вашу функцию
3. Перейдите на вкладку **Тестирование**
4. Используйте тестовый JSON (см. README.md, раздел "Тестирование через консоль")

### 2. Проверка через навык Алисы

1. Скажите Алисе: "Запусти навык Музей техники"
2. Назовите номер экспоната: "Номер 1"
3. Проверьте, что навык отвечает описанием
4. Скажите "Дальше" для продолжения
5. Скажите "Повтори" для повторения

### 3. Проверка логов

1. Откройте функцию в Cloud Functions
2. Перейдите на вкладку **Логи**
3. Проверьте, что логи записываются в формате:
   ```
   [2025-11-22 13:15:30] number=1 status=ok part=0
   ```

## Что делать, если что-то не работает

1. **Проверьте файлы:**
   - `items.json` должен существовать и содержать данные
   - Все `.py` файлы должны быть на месте

2. **Проверьте зависимости:**
   ```bash
   source venv/bin/activate
   pip list | grep boto3
   ```

3. **Проверьте логи:**
   - В тестах смотрите на сообщения об ошибках
   - В Cloud Functions проверяйте вкладку "Логи"

4. **Проверьте конфигурацию:**
   - Убедитесь, что `WORK_MODE=local` для локального тестирования
   - Для Cloud проверьте переменные окружения
